# Revolution HRMS

Windows desktop HRMS and payroll for Indian companies. VB.NET, WinForms, .NET 10, SQL Server Standard, Crystal Reports.
Roles: Developer, Owner, Associate, Operator. Plans: Copper, Silver, Gold, Platinum.

- Plan and phases: `docs/PLAN.md`
- Decisions: `docs/adr/`
- Who owns what: `docs/OWNERSHIP.md`

Build: `dotnet build Revolution.slnx` (Windows, .NET 10 SDK). Test: `dotnet test Revolution.slnx`.
Guards: `./scripts/check-guards.sh`

Setup and first run: `docs/CONTRACT-v0.1.md` (section "Running it"). Module contracts for Brave: the same file.
