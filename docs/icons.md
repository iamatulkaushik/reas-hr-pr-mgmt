# Icons

Generated from the icon map. Ask for an icon with `IconProvider.GetBitmap(AppIcon.X, sizeDip, DeviceDpi, colour)`; colour comes from `Theme`.
Members that share a codepoint do so on purpose. An item not listed here has no icon: show text only.
