# ADR 0006: UI approach

Status: accepted. Owner: Sigma.

- Every form inherits BaseForm (Phase 1): header, toolbar, status bar, validation display, hotkeys.
- One theme class holds colours, spacing (8 px grid), fonts (Segoe UI) and corner radius. No colours or fonts set inside individual forms.
- PerMonitorV2 DPI from the first build. Long work runs async with progress. Keyboard-first for data entry.
- Decided (Phase 1): custom-styled native WinForms controls, no paid suite. Revisit only if a screen needs a grid or scheduler the native controls cannot do; record any change here.
- Theme is applied by `ThemeStyler` when a `BaseForm` loads. The accept button is drawn as the primary button. Set a control's Tag to `ThemeStyler.SkipTag` to opt out.
