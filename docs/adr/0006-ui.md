# ADR 0006: UI approach

Status: accepted, one choice open. Owner: Sigma.

- Every form inherits BaseForm (Phase 1): header, toolbar, status bar, validation display, hotkeys.
- One theme class holds colours, spacing (8 px grid), fonts (Segoe UI) and corner radius. No colours or fonts set inside individual forms.
- PerMonitorV2 DPI from the first build. Long work runs async with progress. Keyboard-first for data entry.
- Open: custom-styled native controls (default) or a paid suite. Decide before Phase 1 ends.
